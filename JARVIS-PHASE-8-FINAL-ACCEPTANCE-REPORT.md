def factorial(n: int) -> int:

## G. Security & Permission Boundaries

1. **Workspace Containment (`WorkspacePolicy`):**
   - Attempt to designate root drive `C:\` -> Rejected with `WorkspacePolicyViolationError: Root drive cannot be an authorized coding workspace: 'C:\'`.
   - Attempt path traversal `..\..\Windows` -> Rejected with `WorkspacePolicyViolationError: Workspace path does not exist / System directory prohibited`.
   - Directory junctions / reparse points -> Checked via Win32 `GetFileAttributesW` & `FILE_ATTRIBUTE_REPARSE_POINT (0x400)` and rejected.
2. **Terminal Agent Isolation (`TerminalService`):**
   - Strictly enforces whitelist-only command registry. Raw shell strings and `shell=True` are disallowed.
   - Command injection attempts using `&`, `|`, `;`, `>`, `<`, `$`, and ``` ` ``` are detected by regex and rejected with `CommandRegistryError`.
   - Environment variables scrubbed: API keys (`GEMINI_API_KEY`, `OPENAI_API_KEY`, `AWS_SECRET_ACCESS_KEY`, etc.) are stripped from child processes.
3. **File System & Archive Security (`FileService`):**
   - Atomic writes via temp files and `os.replace` prevent file corruption during crashes.
   - Windows reserved device names (`CON`, `PRN`, `AUX`, `NUL`, `COM1-9`, `LPT1-9`) and NTFS Alternate Data Streams (`:$DATA`) are blocked.
   - Native Windows Recycle Bin deletion via `SHFileOperationW` (`FO_DELETE` + `FOF_ALLOWUNDO`) verified.
   - ZIP archives inspected without extraction; extraction defends against Zip Slip (`is_relative_to`), archive bombs, and symlinks.
